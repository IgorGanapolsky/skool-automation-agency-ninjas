# Subway-Style Restaurant AI Agent Bundle

This bundle is for quick-service restaurants, sandwich shops, delis, and catering-heavy local operators that want a practical first AI-agent system.

It focuses on boring, useful workflows:

- missed calls
- catering inquiries
- review replies
- staff FAQs
- local promo drafting
- owner visibility

No revenue guarantee. This is an implementation starter and operating checklist.

## How To Use

1. Pick one workflow first. Do not launch every agent at once.
2. Fill in the store details, hours, service area, menu constraints, and escalation rules.
3. Test the agent with real examples before using it with customers.
4. Keep a human handoff rule for pricing, complaints, allergies, refunds, employment, and anything uncertain.
5. Review the owner dashboard weekly.
